# روزیار v0.2

نسخه‌ی دوم برنامه‌ی شخصی برنامه‌ریزی و یادآوری روزانه.

## امکانات فعلی
- صفحه امروز و کار بعدی پیشنهادی
- دسته‌ها: بورس، ساخت‌وساز و پروژه‌ها، خانه و خرید، همسر، افراد، شخصی، بعداً/ایده‌ها
- وضعیت «منتظر دیگران»
- اولویت عادی / مهم / فوری
- تاریخ و ساعت و نوتیفیکیشن
- انجام شد و ۱۰ دقیقه تعویق از نوتیفیکیشن
- تاریخ شمسی و رابط فارسی RTL
- تقویم کارهای زمان‌دار
- ثبت سریع عبارت‌هایی مثل «فردا ساعت ۹» و «فوری»

## جدید در v0.2: روتین من
روتین‌ها هر روز خودکار آماده می‌شوند و لازم نیست دوباره ساخته شوند:
- یادگیری زبان: ۲۰ دقیقه + تمرین آماده‌ی روز
- قرآن: برنامه‌ی کوتاه روزانه برای خواندن همراه ترجمه و تفسیر
- کتاب: پیشنهاد کتاب مشهور/مفید و هدف ۱۰ صفحه در روز
- آب: شمارنده با هدف اولیه ۸ لیوان
- خواب: ثبت ساعت خواب با گام نیم‌ساعته
- پلانک: هدف اولیه ۲ نوبت ۳۰ ثانیه‌ای

لاگ هر روز جداگانه در دیتابیس محلی ذخیره می‌شود تا در نسخه‌های بعد گزارش هفتگی، استمرار (streak) و نمودار اضافه شود.

## ساخت APK بدون Android Studio
پروژه فایل GitHub Actions دارد: `.github/workflows/build-apk.yml`.
بعد از قرار دادن پروژه در GitHub، از بخش Actions می‌توان Workflow «Build Android APK» را اجرا کرد؛ فایل APK در Artifacts همان اجرا قرار می‌گیرد.
